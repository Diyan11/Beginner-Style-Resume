# Responsive Resume Website

A responsive resume webpage created using **HTML and CSS** as part of **Web Engineering Lab 4**.

## Technologies Used

* HTML5
* CSS3
* CSS Media Queries
* CSS Grid

## Features

* Responsive design
* Personal profile
* Education
* Skills
* Projects
* Experience
* Interests
* Mobile-friendly layout

## Responsive Design

The webpage uses **CSS Media Queries** to adapt the layout for:

* Desktop screens
* Tablet screens
* Mobile screens
